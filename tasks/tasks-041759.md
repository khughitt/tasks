The scope workflow requires every reused follow-up to reference its input brief. Reusing a follow-up in another registered project could not link the authoritative brief: the reference validator accepts normalized repo-relative paths and rejected an absolute path. A dated attachment snapshot with an explicit command to retrieve the authoritative task reference is the workaround; native cross-project required-input references would avoid duplicate copies. The existing cross-project-reference feature task is not an open feedback record, so the recurrence command refused; this reports the observed workflow gap without changing that task.
