# Upstream Feedback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `tasks feedback` command that files feedback about the tool as an `idea` in the upstream `tasks` project, recurs on exact repeats, and two supporting changes: `show` resolves foreign ids and `prime` warns about uncommitted task files.

**Architecture:** One new command module, `src/commands/feedback.rs`, that resolves the target project through the registry, then either creates a task in it or appends to a matching one through a guarded read-modify-write. Title matching lives in `src/similarity.rs` with no I/O. `show` gains a foreign branch by opening the other project through the registry; `prime` shells out to `git status` and treats a non-git root as "nothing to report".

**Tech Stack:** Rust 2024 edition, clap derive, serde. Tests: unit tests in-module plus end-to-end tests in `tests/cli.rs` with two projects registered in one temporary home.

**Spec:** `docs/specs/2026-09-03-feedback-design.md` (read it first; each task cites its sections).

## Global Constraints

- Gates before every commit: `cargo test`, `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `tasks check`.
- Rebuild and reinstall after CLI changes: `cargo install --path .`
- JSON output is the contract. New shape: `feedback -> { id, action: "created"|"recurred", path, warnings }`, all fields always present.
- The target is the registry entry whose prefix is exactly `tasks`. There is no configuration key for it.
- Categories are exactly `friction`, `gap`, `idea`, `positive`. Tags written: `feedback`, `<category>`, `from:<prefix>`.
- The command never commits and never sets priority or size.
- Fail early with a typed `Error`; no silent fallbacks. The one documented skip is `prime` in a non-git root.
- Each task below is one tracker task; close it with `tasks done <id> "<what landed>"` in its commit.
- Conventional commits, no AI-attribution trailers.

```rust
use super::Ctx;
use crate::error::{Error, Result};
use crate::format::{validate_body, validate_line, validate_task};
use crate::model::{Status, Task};
use crate::output::{FeedbackOut, Output};
use crate::registry::Registry;
use crate::repo::{CONFIG_REL, Project};

pub const TARGET_PREFIX: &str = "tasks";
pub const CATEGORIES: [&str; 4] = ["friction", "gap", "idea", "positive"];

/// The upstream project: the registry entry whose prefix is `tasks`.
pub fn locate_target(registry: &Registry) -> Result<Project> {
    let Some(root) = registry.project_root(TARGET_PREFIX) else {
        return Err(Error::Config(format!(
            "no project registered as {TARGET_PREFIX:?}; clone the upstream tasks repository and run `tasks init` there"
        )));
    };
    if !root.join(CONFIG_REL).is_file() {
        return Err(Error::Config(format!(
            "project {TARGET_PREFIX:?} at {} has no {CONFIG_REL}; run `tasks init` there",
            root.display()
        )));
    }
    let project = Project::open(root)?;
    if project.prefix != TARGET_PREFIX {
        return Err(Error::Config(format!(
            "registry maps {TARGET_PREFIX:?} to {}, whose prefix is {:?}; fix the registry",
            root.display(),
            project.prefix
        )));
    }
    Ok(project)
}

pub fn run(
    mut ctx: Ctx,
    summary: String,
    category: String,
    body: Option<String>,
) -> Result<Output> {
    if !CATEGORIES.contains(&category.as_str()) {
        return Err(Error::Validation(format!(
            "category must be one of {}",
            CATEGORIES.join(", ")
        )));
    }
    validate_line("summary", &summary)?;
    let body = body.unwrap_or_default();
    validate_body(&body)?;
    let target = locate_target(&ctx.registry)?;
    let from = format!("from:{}", ctx.project.prefix);

    let task = create(&target, summary, body, &category, &from)?;
    let path = target.task_path(&task.id);
    ctx.warnings.push(format!(
        "filed as uncommitted {} in {}; a maintainer there reviews and commits it",
        path.display(),
        target.root.display()
    ));
    Ok(Output::Feedback(FeedbackOut {
        id: task.id.to_string(),
        action: "created".into(),
        path: path.display().to_string(),
        warnings: ctx.warnings,
    }))
}

fn create(target: &Project, summary: String, body: String, category: &str, from: &str) -> Result<Task> {
    let now = crate::time::now();
    let task = Task {
        id: target.new_id()?,
        title: summary,
        status: Status::Idea,
        priority: 2,
        size: None,
        owner: None,
        created: now.clone(),
        updated: now,
        depends: vec![],
        parent: None,
        tags: vec!["feedback".into(), category.into(), from.into()],
        spec: None,
        plan: None,
        step: None,
        body,
        notes: vec![],
    };
    validate_task(&task)?;
    target.validate_docs(&task)?;
    target.write_task(&task)?;
    Ok(task)
}
```

```rust
    /// Paths (relative to the root) of changed or untracked files under tasks/, or `None`
    /// in exactly two documented cases: the root is not inside a git checkout, or there is
    /// no git executable. Any other git failure (permissions, a corrupt repository, an
    /// unexpected exit) is an `io` error, not a skip.
    pub fn uncommitted_task_files(&self) -> Result<Option<Vec<String>>> {
        let output = match std::process::Command::new("git")
            .args(["status", "--porcelain", "--untracked-files=all", "--", "tasks/"])
            .current_dir(&self.root)
            .output()
        {
            Ok(output) => output,
            Err(error) if error.kind() == std::io::ErrorKind::NotFound => return Ok(None),
            Err(error) => return Err(error.into()),
        };
        if !output.status.success() {
            let stderr = String::from_utf8_lossy(&output.stderr);
            if stderr.contains("not a git repository") {
                return Ok(None);
            }
            return Err(Error::Io(format!(
                "git status in {} failed ({}): {}",
                self.root.display(),
                output.status,
                stderr.trim()
            )));
        }
        let files = String::from_utf8_lossy(&output.stdout)
            .lines()
            .filter(|line| line.len() > 3)
            .map(|line| line[3..].to_string())
            .filter(|path| !path.rsplit('/').next().unwrap_or("").starts_with('.'))
            .collect();
        Ok(Some(files))
    }
```

The dot-file filter drops `.config.toml` and edit temps so an untouched fresh init in a repo does not warn about its own config; the config is committed with the first task in practice, and if it is not, `git status` itself says so.

```rust
use crate::model::{Task, TaskId};

pub const SIMILAR_THRESHOLD: f64 = 0.6;

/// Lowercase ASCII-alphanumeric tokens of three or more characters, in order.
pub fn tokens(title: &str) -> Vec<String> {
    title
        .to_ascii_lowercase()
        .split(|c: char| !c.is_ascii_alphanumeric())
        .filter(|word| word.len() >= 3)
        .map(str::to_string)
        .collect()
}

pub fn jaccard(a: &[String], b: &[String]) -> f64 {
    let a: std::collections::BTreeSet<&String> = a.iter().collect();
    let b: std::collections::BTreeSet<&String> = b.iter().collect();
    let union = a.union(&b).count();
    if union == 0 {
        return 0.0;
    }
    a.intersection(&b).count() as f64 / union as f64
}

#[derive(Debug, PartialEq)]
pub enum Match {
    Exact(TaskId),
    /// Candidates at or above the threshold, best first, ties to the older task.
    Similar(Vec<(TaskId, String)>),
    None,
}

/// `candidates` are already filtered to open tasks tagged `feedback`.
pub fn find(summary: &str, candidates: &[Task]) -> Match {
    let wanted = tokens(summary);
    let mut similar: Vec<(f64, &Task)> = Vec::new();
    for task in candidates {
        let have = tokens(&task.title);
        if have == wanted {
            return Match::Exact(task.id.clone());
        }
        let score = jaccard(&wanted, &have);
        if score >= SIMILAR_THRESHOLD {
            similar.push((score, task));
        }
    }
    if similar.is_empty() {
        return Match::None;
    }
    similar.sort_by(|(x, a), (y, b)| {
        y.partial_cmp(x)
            .unwrap()
            .then_with(|| a.created.cmp(&b.created))
            .then_with(|| a.id.cmp(&b.id))
    });
    Match::Similar(
        similar
            .into_iter()
            .map(|(_, task)| (task.id.clone(), task.title.clone()))
            .collect(),
    )
}
```

```rust
fn recur_into(
    ctx: &Ctx,
    target: &Project,
    id: &TaskId,
    summary: &str,
    body: &str,
    category: &str,
    from: &str,
) -> Result<Task> {
    if !body.is_empty() {
        validate_note_text(body)?;
    }
    // Fixed author: the reporter's TASKS_OWNER, branch, or user name must not leak into
    // the public upstream file. The reporting project is already in the note text.
    let prefix = ctx.project.prefix.clone();

        append_note(task, NOTE_AUTHOR, &format!("feedback from {prefix}: {summary}"))?;
        if !body.is_empty() {
            append_note(task, NOTE_AUTHOR, &format!("detail from {prefix}: {body}"))?;
        }
        for tag in [from, category] {

            }
        }

pub const NOTE_AUTHOR: &str = "feedback";

/// Read, mutate, and replace `id` in `target`, retrying from the read when the file
/// changed between the read and the moment before the replace. Gives up after eight
/// rounds with `concurrent_modification`. `write_task` runs the project-level checks
/// (doc roots, parent), so this path is as validated as `save`.
pub fn guarded_update(
    target: &Project,
    id: &TaskId,
    mut mutate: impl FnMut(&mut Task) -> Result<()>,
) -> Result<Task> {
    for _ in 0..8 {
        let (mut task, raw) = target.read_task_with_raw(id)?;
        mutate(&mut task)?;
        task.updated = crate::time::now();
        validate_task(&task)?;
        if target.read_raw(id)? != raw {
            continue;
        }
        target.write_task(&task)?;
        return Ok(task);
    }
    Err(Error::ConcurrentModification(
        id.to_string(),
        "another writer kept changing it; retry".into(),
    ))
}
```
