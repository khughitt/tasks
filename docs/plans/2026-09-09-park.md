# Park Implementation Plan

**Status:** planned (2026-09-09); not yet implemented

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tasks park <id> "<next step>" [--waiting-on user|agent]` sets a task down by recording a park entry in the shared claim store; `start` resumes it, `prime`/`next`/`ready`/`list --parked` surface it, and `rename` carries it.

**Architecture:** The per-prefix store (`src/claims.rs`) gains a second entry kind, `Park`, beside `Claim`, with one entry per task id and no liveness. `park` is a write command that appends a note to the record and writes the entry through the existing validate-then-file-then-store transaction in `save`. Clearing is a property of the store transitions the claim guard already records: acquiring a claim on `start` (or any change into `doing`) replaces a park, releasing on `done`/`drop` removes it, and status-preserving editor saves stop touching the store. Read commands attach `park` to every task object the way they attach `claim`, and a new `commands/parked.rs` builds the parked rows (local, resolved from another checkout, or unresolved payload rows) and the `next` candidates. `rename` migrates park entries into the target store under the inventory's digest discipline.

**Tech Stack:** Rust 2024, clap 4.6, serde, toml, sha2 (already dependencies). No new dependencies.

**Spec:** `docs/specs/2026-09-09-park-design.md`

**Task:** `tasks-08b9d5`

## Global Constraints

- **JSON output is the contract; every change here is additive.** New keys: `park` on `Task`-bearing objects (`TaskSummary`, `ShowFields`), `parked` on `prime`, `phase` on parked rows, `parks` on `rename`. Nothing existing changes shape or meaning. (`AGENTS.md`; spec §5.4)
- **The store is the only source of current parking.** No frontmatter field is added anywhere. The record gains a note. (spec §2.1)
- **This crate has no library target, and every module is private.** An unused `pub fn`, an unread struct field, or an unused enum variant fails `cargo clippy --all-targets -- -D warnings` with `dead_code`; use from `#[cfg(test)]` does not count. Every helper below is introduced in the task whose production code consumes it, and the tasks are grouped so each commit's gate can pass. Unit tests run as `cargo test --bin tasks <filter>`; end-to-end tests as `cargo test --test cli <filter>`.
- **Fail early with a typed error; no silent fallbacks.** The one designed exception is spec §5.3: a park entry whose checkout is unavailable is rendered from its payload with a warning naming the failure, never dropped and never an error.
- **Gates.** `just check` before every commit (fmt, clippy `-D warnings`, `tasks check`); `just test` is `cargo test`. Rebuild and reinstall after CLI changes so the tracker in use is the code under test: `cargo install --path .`.
- **Struct-literal sites that break when a field is added** (each task names the ones it touches): `Identity` (`src/claims.rs:41,47,53`); `TaskSummary` (`src/output.rs:185` and the test helper `row` at `:840`); `ShowFields` (`src/commands/show.rs:101`); `Inventory` (`src/rename/inventory.rs:101` and the test helper `baseline` in `src/rename/classify.rs:219`); `PrimeOut` (`src/commands/list.rs`, end of `prime`); `RenameOut` (`src/rename/mod.rs`, in `run`).
- **`toml` writes an empty map as a bare table header.** `StoreFile { claims: {} }` serializes to `[claims]`. Both store maps carry `skip_serializing_if = "BTreeMap::is_empty"` so an empty kind is absent from the file, which is what the migrated-store assertions in Tasks 1 and 5 rely on. `#[serde(default)]` keeps reading either spelling.
- **End-to-end tests isolate the store and the session.** `TestEnv::cmd` sets `HOME` to a temp dir (so the store lands under it), and `as_agent(&env, dir, "name")` sets `TASKS_SESSION` plus a live pid. A test that parks or claims must run through `as_agent` so its session is named; `env.json` alone resolves to the Unix session id, which is the same for every command in the test. `at` has second precision: two parks whose order matters need a `sleep` of 1100 ms between them.
- **Each plan task has a step child under `tasks-08b9d5`**; the ids are listed at the end of this header once the children exist. `tasks start <step>` before its first step and `tasks done <step> "<what landed>"` in the same commit as its code; the commit blocks below include the `done`.
- **Composition > inheritance. Explicit > defensive.** No paths like `/home/<user>` in comments or docs. Conventional commits; **no AI-attribution trailers or footers**.

**Step children:** Task 1 `tasks-4516b1`, Task 2 `tasks-9a2a5d`, Task 3 `tasks-1896ea`, Task 4 `tasks-31d737`, Task 5 `tasks-32955b`, Task 6 `tasks-6870de`.

```rust
    pub host: String,
    pub worktree: String,
    pub at: String,
    pub next_step: String,

    parks: BTreeMap<String, Park>,
}
```

```rust
    pub fn load_from(path: &Path) -> Result<ClaimStore> {
        let file = match std::fs::read_to_string(path) {
            Ok(text) => toml::from_str::<StoreFile>(&text)
                .map_err(|error| Error::Config(format!("{}: {error}", path.display())))?,
            Err(error) if error.kind() == std::io::ErrorKind::NotFound => StoreFile::default(),
            Err(error) => return Err(error.into()),
        };
        let StoreFile { claims, parks } = file;
        for (id, claim) in &claims {
            for (field, value) in [("started", &claim.started), ("seen", &claim.seen)] {
                crate::time::parse(value).map_err(|error| {
                    Error::Config(format!(
                        "{}: claim {id} has an unreadable {field}: {error}",
                        path.display()
                    ))
                })?;
            }
        }
        for (id, park) in &parks {
            crate::time::parse(&park.at).map_err(|error| {
                Error::Config(format!(
                    "{}: park {id} has an unreadable at: {error}",
                    path.display()
                ))
            })?;
            crate::format::validate_line("next_step", &park.next_step)
                .map_err(|error| Error::Config(format!("{}: park {id}: {error}", path.display())))?;
            if claims.contains_key(id) {
                return Err(Error::Config(format!(
                    "{}: {id} has both a claim and a park; one entry per task",
                    path.display()
                )));
            }
        }
        Ok(ClaimStore {
            path: path.to_path_buf(),
            claims,
            parks,
        })
    }
```

```rust
/// Every claim in scope, with its liveness verdict, and every park entry, read once per
/// command.
#[derive(Debug, Default)]
pub struct ClaimSnapshot {
    by_id: BTreeMap<String, (Claim, Liveness)>,
    parks: BTreeMap<String, Park>,
}

impl ClaimSnapshot {
    pub fn load<'a>(prefixes: impl Iterator<Item = &'a str>) -> Result<ClaimSnapshot> {
        let paths = prefixes
            .map(ClaimStore::path_for)
            .collect::<Result<Vec<_>>>()?;
        Self::load_from_paths(paths.into_iter())
    }

    /// The path form, so a test can point at a file without setting the environment.
    pub fn load_from_paths(paths: impl Iterator<Item = PathBuf>) -> Result<ClaimSnapshot> {
        let mut by_id = BTreeMap::new();
        let mut parks = BTreeMap::new();
        for path in paths {
            let store = ClaimStore::load_from(&path)?;
            for (id, claim) in store.iter() {
                by_id.insert(id.clone(), (claim.clone(), liveness(claim)));
            }
            for (id, park) in store.parks() {
                parks.insert(id.clone(), park.clone());
            }
        }
        Ok(ClaimSnapshot { by_id, parks })
    }

    pub fn park(&self, id: &TaskId) -> Option<&Park> {
        self.parks.get(&id.to_string())
    }
```

```rust
use super::{ClaimIntent, Ctx, append_note, id_out, load, owner_name, save};
use crate::claims::{Liveness, Park, WaitingOn};
use crate::error::{Error, Result};
use crate::output::Output;

/// Set a task down (spec §3). Validate everything, refuse a foreign live claim, then let
/// `save` write the note and the entry in that order.
pub fn run(mut ctx: Ctx, id: String, next_step: String, waiting_on: String) -> Result<Output> {
    let mut task = load(&ctx, &id)?;
    if !task.status.is_open() {
        return Err(Error::InvalidTransition(
            task.status.as_str().into(),
            "parked".into(),
        ));
    }
    crate::format::validate_line("next_step", &next_step)?;
    let waiting_on = WaitingOn::parse(&waiting_on)?;
    let owner = owner_name(&ctx.project)?;
    let me = crate::claims::identity()?;

    // The claim rules of §3.1, as a guard: a live foreign claim refuses (no --force), a
    // stale one is taken over with the warning `start` gives, our own is simply replaced.
    let takeover = {
        let store = ctx.claims_mut()?;
        match store.get(&task.id) {
            Some(existing) if existing.session != me.session => {
                let live = crate::claims::liveness(existing);
                let description = Ctx::describe_claim(existing, &live);
                match live {
                    Liveness::Live => {
                        return Err(Error::Claimed(task.id.to_string(), description));
                    }
                    Liveness::Stale(_) => Some(format!("took over {description}")),
                }
            }
            _ => None,
        }
    };
    if let Some(warning) = takeover {
        ctx.warnings.push(warning);
    }

    append_note(
        &mut task,
        &owner,
        &format!("parked (waiting on {}): {next_step}", waiting_on.as_str()),
    )?;
    let park = Park {
        owner,
        session: me.tagged,
        host: crate::claims::hostname(),
        worktree: ctx.project.root.display().to_string(),
        at: crate::time::now(),
        next_step,
        waiting_on,
        title: task.title.clone(),
    };
    ctx.pending_claim = Some((task.id.clone(), ClaimIntent::Park(park)));
    save(&mut ctx, &mut task)?;
    Ok(id_out(ctx, &task))
}
```

`pending_claim` is a private field of `Ctx`; `commands::park` is a child module of `commands`, so it can set it, exactly as `commands/mod.rs`'s own `claim_guard` does.

```rust
/// drift from the spec and plan links. See docs/specs/2026-09-09-park-design.md §4.2.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "lowercase")]
pub enum Phase {
    Brainstorming,
    Planning,
    Implementing,
}

impl Phase {
    /// First match wins. The last arm is deliberate: a todo with neither spec nor plan
    /// is scoped work that never needed a design, not a brainstorm.
    pub fn of(task: &Task) -> Phase {
        if task.status == Status::Idea {

            return Phase::Implementing;
        }
        if task.spec.is_some() {
            return Phase::Planning;
        }
        Phase::Implementing
    }

        match self {
            Phase::Brainstorming => "brainstorming",
            Phase::Planning => "planning",
            Phase::Implementing => "implementing",
        }
    }
```

```rust
/// Two lines per parked task: the row, then the next step. Status `?` and phase `-` mark
/// an unresolved entry.
pub fn parked_table(rows: &[ParkedRow], painter: &Painter) -> String {
    let mut rendered = String::new();
    for row in rows {
        let Some(park) = &row.park else {
            continue;
        };
        let id = painter.paint(Style::Chrome, &row.id);
        let status = match row.status {
            Some(status) => painter.paint(Style::Status(status), &format!("{:<7}", status.as_str())),

        let phase = format!(

            row.phase.map(crate::model::Phase::as_str).unwrap_or("-")
        );
        rendered.push_str(&format!(
            "{id}  {status} {phase} waits on {:<5} {}  {}\n",
            park.waiting_on.as_str(),
            crate::time::day(&park.at),
            row.title
        ));
        rendered.push_str(&painter.paint(Style::Chrome, &format!("        next: {}\n", park.next_step)));
```

```rust
//! entry means in a read command, so `prime`, `list --parked`, and `next` cannot drift.

use super::ReadCtx;
use crate::claims::{ClaimSnapshot, Park, WaitingOn};
use crate::error::Result;
use crate::model::{Phase, Status, Task, TaskId};
use crate::output::{ParkedRow, TaskSummary};
use crate::registry::Registry;
use crate::repo::Project;
use std::path::Path;

/// Every park entry in scope as a row, most recently parked first. A task in the scan is
/// a local row. A store-only entry is resolved by scanning the checkout it names, or
/// rendered from its payload with a warning; a read never removes an entry (spec §5.3).
pub fn rows(ctx: &mut ReadCtx, all: &[Task], claims: &ClaimSnapshot) -> Result<Vec<ParkedRow>> {
    let mut entries: Vec<(&String, &Park)> = claims.parks().collect();
    entries.sort_by(|a, b| b.1.at.cmp(&a.1.at).then_with(|| a.0.cmp(b.0)));
    let mut rows = Vec::new();
    for (key, park) in entries {
        let id = match TaskId::parse(key) {
            Ok(id) => ctx.registry.canonical_id(&id),
            Err(error) => {
                ctx.warnings.push(format!("park entry {key:?} is not a task id ({error}); shown as is"));
                rows.push(ParkedRow::unresolved(key, park));
                continue;
            }
        };
        if let Some(task) = all.iter().find(|task| task.id == id) {
            rows.push(ParkedRow::resolved(
                TaskSummary::of(task, all, Some(claims), &ctx.registry),
                Phase::of(task),
            ));
            continue;
        }
        match resolve_elsewhere(&id, park, claims, &ctx.registry) {
            Ok(Some(row)) => {
                ctx.warnings.push(format!(
                    "{id} is parked in {}; resume it from that checkout",
                    park.worktree
                ));
                rows.push(row);
            }
            Ok(None) => {
                ctx.warnings.push(format!(
                    "{id} is parked in {}, which is unavailable; the row shows the park entry only",
                    park.worktree
                ));
                rows.push(ParkedRow::unresolved(key, park));
            }
            Err(error) => {
                ctx.warnings.push(format!(
                    "{id} is parked in {}, which is unavailable ({error}); the row shows the park entry only",
                    park.worktree
                ));
                rows.push(ParkedRow::unresolved(key, park));
            }
        }
    }
    Ok(rows)
}

/// The originating checkout's own scan, so children and local dependencies are counted
/// where they live. `None` when the path is not a checkout of this prefix or the task is
/// not in it; `Err` when it is one and cannot be read.
fn resolve_elsewhere(
    id: &TaskId,
    park: &Park,
    claims: &ClaimSnapshot,
    registry: &Registry,
) -> Result<Option<ParkedRow>> {
    let root = Path::new(&park.worktree);
    if !crate::scope::has_config(root)? {
        return Ok(None);
    }
    let project = Project::open(root)?;
    if project.prefix != id.prefix {
        return Ok(None);
    }
    let scan = project.scan()?;
    let Some(task) = scan.iter().find(|task| task.id == *id) else {
        return Ok(None);
    };
    Ok(Some(ParkedRow::resolved(
        TaskSummary::of(task, &scan, Some(claims), registry),
        Phase::of(task),
    )))
}

/// The parked tasks `next` may hand out (spec §5.2), most recently parked first: in the
/// scan (a store-only entry cannot be started from here), waiting on the agent, open and
/// not blocked, every dependency resolved and closed, no children.
pub fn candidates(ctx: &mut ReadCtx, all: &[Task], claims: &ClaimSnapshot) -> Result<Vec<Task>> {
    let mut found: Vec<(String, Task)> = Vec::new();
    for task in all {
        let Some(park) = claims.park(&task.id) else {
            continue;
        };
        if park.waiting_on != WaitingOn::Agent
            || !task.status.is_open()
            || task.status == Status::Blocked
            || !crate::hierarchy::children(all, &task.id, &ctx.registry).is_empty()
        {
            continue;
        }
        let mut held = false;
        for dependency in &task.depends {
            match super::list::resolve_dependency(ctx, all, dependency)? {
                Some(dependency) if !dependency.status.is_open() => {}
                // An unreachable dependency holds the task, as `ready` and `done` treat it.
                _ => {
                    held = true;
                    break;
                }
            }
        }
        if !held {
            found.push((park.at.clone(), task.clone()));
        }
    }
    found.sort_by(|a, b| b.0.cmp(&a.0).then_with(|| a.1.id.cmp(&b.1.id)));
    Ok(found.into_iter().map(|(_, task)| task).collect())
}
```

```rust
/// `list --parked` (spec §5.1): the parked rows in park order. Filters apply to what a row
/// knows; an unresolved row knows nothing the filters ask about, so any filter drops it
/// while the warning still names it. `--parent` may name a task that exists only in the
/// checkout a resolved row came from, so it is validated against the rows as well as the
/// scan.
fn list_parked(
    mut ctx: ReadCtx,
    statuses: Vec<Status>,
    tags: Vec<String>,
    owner: Option<String>,
    source: Option<String>,
    parent: Option<String>,
) -> Result<Output> {
    let (all, claims) = ctx.scan_with_claims()?;
    let parent = parent
        .as_deref()
        .map(|id| super::parse_id(&ctx.registry, id))
        .transpose()?;
    let rows: Vec<ParkedRow> = super::parked::rows(&mut ctx, &all, &claims)?;
    let warnings = std::mem::take(&mut ctx.warnings);
    let registry = &ctx.registry;
    let row_parent = |row: &ParkedRow| -> Option<TaskId> {
        row.parent
            .as_deref()
            .and_then(|parent| TaskId::parse(parent).ok())
            .map(|id| registry.canonical_id(&id))
    };
    if let Some(parent) = &parent
        && !all.iter().any(|task| task.id == *parent)
        && !rows.iter().any(|row| row_parent(row).as_ref() == Some(parent))
    {
        return Err(Error::TaskNotFound(parent.to_string()));
    }
    let filtered = !statuses.is_empty()
        || !tags.is_empty()
        || owner.is_some()
        || source.is_some()
        || parent.is_some();
    let tasks: Vec<ParkedRow> = rows
        .into_iter()
        .filter(|row| {
            let Some(status) = row.status else {
                return !filtered;
            };
            let status_ok = if statuses.is_empty() {
                status.is_open()
            } else {
                statuses.contains(&status)
            };
            let tags_ok = tags.iter().all(|tag| row.tags.contains(tag));
            let owner_ok = owner
                .as_ref()
                .is_none_or(|value| row.owner.as_ref() == Some(value));
            let source_ok = source
                .as_ref()
                .is_none_or(|value| row.source.as_ref() == Some(value));
            let parent_ok = parent
                .as_ref()
                .is_none_or(|p| row_parent(row).as_ref() == Some(p));
            status_ok && tags_ok && owner_ok && source_ok && parent_ok
        })
        .collect();
    Ok(Output::Parked(ParkedOut { tasks, warnings }))
}
```
