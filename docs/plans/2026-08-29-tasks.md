# tasks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `tasks` CLI — a single Rust binary that manages one-markdown-file-per-task trackers checked into project repos, with JSON-first output, dependencies (cross-project), spec/plan links, and drift checking.

**Architecture:** Pure library modules (`model`, `frontmatter`, `format`, `query`) with no I/O, composed by `repo`/`registry` (filesystem) and thin `commands/*` modules that the clap-defined `cli` dispatches. Every command scans `tasks/*.md`; every write builds the whole file in memory and renames it into place. Each command returns one `serde::Serialize` struct that `output` renders as JSON or `--pretty` text.

**Tech Stack:** Rust 1.98, edition 2024. `clap 4` (derive), `serde`/`serde_json`, `toml 1`, `time 0.3`, `fastrand 2`, `thiserror 2`. Tests: `assert_cmd 2`, `tempfile 3`, `predicates 3`.

**Spec:** `docs/specs/2026-08-29-tasks-design.md`

## Global Constraints

- Frontmatter is a strict subset of YAML: `key: scalar`, `key: [a, b]`, `key: "quoted"`; unknown keys are errors (spec §3.1). No YAML library.
- Ids are `<prefix>-<hex6>`, prefix `[a-z][a-z0-9]{1,7}`, six lowercase hex digits (spec §4).
- `spec` must be under `docs/specs/`, `plan` under `docs/plans/`; both fixed (spec §2).
- Times: UTC RFC 3339, second precision, `Z` suffix (spec §3.1).
- JSON to stdout by default; `--pretty` or `TASKS_FORMAT=pretty` for text. No TTY detection (spec §5).
- Errors: `{"error":{"kind","detail"}}` on stderr, exit 1; clap usage errors exit 2 (spec §5.1). Every success payload has `warnings: [string]`.
- `## Notes` line is reserved (spec §3.2). Note text is single-line.
- Writes go through `tasks/.<id>.tmp` + rename (spec §10).
- Conventional commits; no AI attribution trailers. Never put absolute home paths in code or docs.
- Fail early: no silent fallbacks, no defensive defaults for malformed input.

```rust
pub fn now() -> String {
    OffsetDateTime::now_utc()
        .replace_nanosecond(0)
        .expect("zero ns is valid")
        .format(&Rfc3339)
        .expect("rfc3339")
}

pub fn parse(s: &str) -> Result<OffsetDateTime> {
    if !s.ends_with('Z') {
        return Err(Error::Validation(format!("timestamp {s:?} must be UTC with Z suffix")));
    }
    OffsetDateTime::parse(s, &Rfc3339)
        .map_err(|e| Error::Validation(format!("bad timestamp {s:?}: {e}")))
}
```

```rust
use crate::error::{Error, Result};
use serde::Serialize;
use std::fmt;

#[derive(Debug, Clone, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct TaskId {
    pub prefix: String,
    pub hex: String,
}

impl TaskId {
    pub fn parse(s: &str) -> Result<TaskId> {
        let Some((prefix, hex)) = s.rsplit_once('-') else {
            return Err(Error::InvalidId(s.into(), "expected <prefix>-<hex6>".into()));
        };
        if !is_valid_prefix(prefix) {
            return Err(Error::InvalidId(s.into(), "prefix must match [a-z][a-z0-9]{1,7}".into()));
        }
        let hex_ok = hex.len() == 6
            && hex.chars().all(|c| c.is_ascii_digit() || ('a'..='f').contains(&c));
        if !hex_ok {
            return Err(Error::InvalidId(s.into(), "suffix must be six lowercase hex digits".into()));
        }
        Ok(TaskId { prefix: prefix.into(), hex: hex.into() })
    }
}

pub fn is_valid_prefix(p: &str) -> bool {
    let mut chars = p.chars();
    (2..=8).contains(&p.len())
        && matches!(chars.next(), Some(c) if c.is_ascii_lowercase())
        && chars.all(|c| c.is_ascii_lowercase() || c.is_ascii_digit())
}

impl fmt::Display for TaskId {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}-{}", self.prefix, self.hex)
    }
}

impl Serialize for TaskId {
    fn serialize<S: serde::Serializer>(&self, s: S) -> std::result::Result<S::Ok, S::Error> {
        s.serialize_str(&self.to_string())
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize)]
#[serde(rename_all = "lowercase")]
pub enum Status { Idea, Todo, Doing, Blocked, Done, Dropped }

impl Status {
    pub const ALL: [Status; 6] =
        [Status::Idea, Status::Todo, Status::Doing, Status::Blocked, Status::Done, Status::Dropped];

    pub fn parse(s: &str) -> Result<Status> {
        Status::ALL.into_iter().find(|st| st.as_str() == s)
            .ok_or_else(|| Error::Validation(format!("unknown status {s:?}")))
    }

    pub fn as_str(self) -> &'static str {
        match self {
            Status::Idea => "idea", Status::Todo => "todo", Status::Doing => "doing",
            Status::Blocked => "blocked", Status::Done => "done", Status::Dropped => "dropped",
        }
    }

    pub fn is_open(self) -> bool { !matches!(self, Status::Done | Status::Dropped) }

    /// Spec §3.3 transition table. Same-status is always allowed (no-op).
    pub fn can_transition(from: Status, to: Status) -> bool {
        if from == to { return true; }
        match (from.is_open(), to.is_open()) {
            (true, _) => true,                   // open -> open, open -> closed
            (false, true) => to == Status::Todo, // closed -> todo only
            (false, false) => false,             // done <-> dropped
        }
    }
}

pub enum Size { Xs, S, M, L, Xl }

impl Size {
    pub const ALL: [Size; 5] = [Size::Xs, Size::S, Size::M, Size::L, Size::Xl];
    pub fn parse(s: &str) -> Result<Size> {
        Size::ALL.into_iter().find(|z| z.as_str() == s)
            .ok_or_else(|| Error::Validation(format!("unknown size {s:?}")))
    }
    pub fn as_str(self) -> &'static str {
        match self { Size::Xs => "xs", Size::S => "s", Size::M => "m", Size::L => "l", Size::Xl => "xl" }
    }
}

pub struct Note {
    pub at: String,
    pub by: String,
    pub text: String,
}

pub struct Task {

    pub priority: u8,
    pub size: Option<Size>,

    pub tags: Vec<String>,
    pub spec: Option<String>,
    pub plan: Option<String>,

    pub notes: Vec<Note>,
}
```

Grammar (all that is accepted):
- One `key: value` per line; key `[a-z_]+`; exactly one space after the colon; empty value is an error (write `""`).
- Scalar: `"..."` with `\"` and `\\` escapes only, or a bare token containing none of `" [ ] , # : \` and no leading/trailing whitespace.
- List: `[]` or `[item, item]` of scalars as above.
- Serialize quotes a scalar iff it is empty, has surrounding whitespace, contains a reserved character, or would read as a YAML non-string (`true`, `false`, `null`, `~`, `yes`, `no`, or a number).

```rust
use crate::error::{Error, Result};

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Value {
    Scalar(String),
    List(Vec<String>),
    /// Emitted verbatim by `serialize`; `parse` never yields it (it reads `2` as `Scalar("2")`).
    Raw(String),
}

const RESERVED: &str = "\"[],#:\\";

fn bad(detail: impl Into<String>) -> Error {
    Error::Parse { file: "<frontmatter>".into(), detail: detail.into() }
}

pub fn parse(text: &str) -> Result<Vec<(String, Value)>> {
    let mut out: Vec<(String, Value)> = Vec::new();
    for (n, line) in text.lines().enumerate() {
        let n = n + 1;
        let Some((key, rest)) = line.split_once(':') else {
            return Err(bad(format!("line {n}: expected `key: value`")));
        };
        if key.is_empty() || !key.chars().all(|c| c.is_ascii_lowercase() || c == '_') {
            return Err(bad(format!("line {n}: bad key {key:?}")));
        }
        let Some(rest) = rest.strip_prefix(' ') else {
            return Err(bad(format!("line {n}: expected one space after `{key}:`")));
        };
        if rest.is_empty() {
            return Err(bad(format!("line {n}: empty value for {key}; use \"\"")));
        }
        if out.iter().any(|(k, _)| k == key) {
            return Err(bad(format!("line {n}: duplicate key {key}")));
        }
        let value = if let Some(inner) = rest.strip_prefix('[') {
            let inner = inner.strip_suffix(']').ok_or_else(|| bad(format!("line {n}: unterminated list")))?;
            Value::List(parse_items(inner).map_err(|d| bad(format!("line {n}: {d}")))?)
        } else {
            Value::Scalar(parse_scalar(rest).map_err(|d| bad(format!("line {n}: {d}")))?)
        };
        out.push((key.to_string(), value));
    }
    Ok(out)
}

fn parse_items(inner: &str) -> std::result::Result<Vec<String>, String> {
    let inner = inner.trim();
    if inner.is_empty() { return Ok(vec![]); }
    let mut items = Vec::new();
    let mut rest = inner;
    loop {
        rest = rest.trim_start();
        let (item, after) = if rest.starts_with('"') {
            take_quoted(rest)?
        } else {
            let end = rest.find(',').unwrap_or(rest.len());
            (parse_scalar(rest[..end].trim())?, &rest[end..])
        };
        items.push(item);
        let after = after.trim_start();
        if after.is_empty() { return Ok(items); }
        rest = after.strip_prefix(',').ok_or_else(|| format!("expected `,` before {after:?}"))?;
        if rest.trim().is_empty() { return Err("trailing comma".into()); }
    }
}

fn parse_scalar(tok: &str) -> std::result::Result<String, String> {
    if tok.starts_with('"') {
        let (s, after) = take_quoted(tok)?;
        if !after.is_empty() { return Err(format!("unexpected text after quoted string: {after:?}")); }
        return Ok(s);
    }
    if tok.trim() != tok { return Err(format!("bare scalar {tok:?} has surrounding whitespace")); }
    if tok.chars().any(|c| RESERVED.contains(c)) {
        return Err(format!("bare scalar {tok:?} contains a reserved character; quote it"));
    }
    Ok(tok.to_string())
}

/// Parses a leading `"..."`; returns the unescaped string and the remainder after the closing quote.
fn take_quoted(s: &str) -> std::result::Result<(String, &str), String> {
    let mut out = String::new();
    let mut chars = s[1..].char_indices();
    while let Some((i, c)) = chars.next() {
        match c {
            '\\' => match chars.next() {
                Some((_, '"')) => out.push('"'),
                Some((_, '\\')) => out.push('\\'),
                other => return Err(format!("bad escape {other:?}")),
            },
            '"' => return Ok((out, &s[1 + i + 1..])),
            c => out.push(c),
        }
    }
    Err("unterminated quoted string".into())
}

fn quote(s: &str) -> String {
    let mut q = String::with_capacity(s.len() + 2);
    q.push('"');
    for c in s.chars() {
        if c == '"' || c == '\\' { q.push('\\'); }
        q.push(c);
    }
    q.push('"');
    q
}

fn needs_quotes(s: &str) -> bool {
    s.is_empty()
        || s.trim() != s
        || s.chars().any(|c| RESERVED.contains(c))
        || matches!(s, "true" | "false" | "null" | "~" | "yes" | "no")
        || s.parse::<f64>().is_ok()
}

fn render_scalar(s: &str) -> String {
    if needs_quotes(s) { quote(s) } else { s.to_string() }
}

pub fn serialize(pairs: &[(String, Value)]) -> String {
    let mut out = String::new();
    for (k, v) in pairs {
        out.push_str(k);
        out.push_str(": ");
        match v {
            Value::Scalar(s) => out.push_str(&render_scalar(s)),
            Value::Raw(s) => out.push_str(s),
            Value::List(items) => {
                let rendered: Vec<String> = items.iter().map(|i| render_scalar(i)).collect();
                out.push('[');
                out.push_str(&rendered.join(", "));
                out.push(']');
            }
        }
        out.push('\n');
    }
    out
}
```

```rust
use crate::error::{Error, Result};
use crate::frontmatter::{self, Value};
use crate::model::{Note, Size, Status, Task, TaskId};

pub const NOTES_DELIMITER: &str = "## Notes";
const KEYS: [&str; 13] = ["id", "title", "status", "priority", "size", "owner", "created", "updated", "depends", "tags", "spec", "plan", "step"];

fn perr(file: &str, detail: impl Into<String>) -> Error {
    Error::Parse { file: file.to_string(), detail: detail.into() }
}

pub fn parse_task(text: &str, file: &str) -> Result<Task> {
    let rest = text.strip_prefix("---\n").ok_or_else(|| perr(file, "missing opening ---"))?;
    let (fm, after) = rest.split_once("\n---\n").ok_or_else(|| perr(file, "missing closing ---"))?;
    let pairs = frontmatter::parse(&format!("{fm}\n")).map_err(|e| match e {
        Error::Parse { detail, .. } => perr(file, detail),
        e => e,
    })?;
    for (k, _) in &pairs {
        if !KEYS.contains(&k.as_str()) { return Err(perr(file, format!("unknown key {k:?}"))); }
    }
    let scalar = |k: &str| -> Result<Option<String>> {
        match pairs.iter().find(|(key, _)| key == k) {
            None => Ok(None),
            Some((_, Value::Scalar(s))) => Ok(Some(s.clone())),
            Some((_, Value::List(_) | Value::Raw(_))) => Err(perr(file, format!("{k} must be a scalar"))),
        }
    };
    let required = |k: &str| -> Result<String> { scalar(k)?.ok_or_else(|| perr(file, format!("missing {k}"))) };
    let list = |k: &str| -> Result<Vec<String>> {
        match pairs.iter().find(|(key, _)| key == k) {
            None => Err(perr(file, format!("missing {k}"))),
            Some((_, Value::List(v))) => Ok(v.clone()),
            Some((_, Value::Scalar(_) | Value::Raw(_))) => Err(perr(file, format!("{k} must be a list"))),
        }
    };

    let priority: u8 = required("priority")?.parse().map_err(|_| perr(file, "priority must be an integer 0-4"))?;
    if priority > 4 { return Err(perr(file, "priority must be 0-4")); }
    let created = required("created")?;
    let updated = required("updated")?;
    crate::time::parse(&created).map_err(|e| perr(file, e.to_string()))?;
    crate::time::parse(&updated).map_err(|e| perr(file, e.to_string()))?;
    let depends = list("depends")?.iter().map(|d| TaskId::parse(d)).collect::<Result<Vec<_>>>()
        .map_err(|e| perr(file, e.to_string()))?;

    let (body, notes) = split_body_notes(after, file)?;

    let task = Task {
        id: TaskId::parse(&required("id")?).map_err(|e| perr(file, e.to_string()))?,
        title: required("title")?,
        status: Status::parse(&required("status")?).map_err(|e| perr(file, e.to_string()))?,
        priority,
        size: scalar("size")?.map(|s| Size::parse(&s)).transpose().map_err(|e| perr(file, e.to_string()))?,
        owner: scalar("owner")?,
        created,
        updated,
        depends,
        tags: list("tags")?,
        spec: scalar("spec")?,
        plan: scalar("plan")?,
        step: scalar("step")?,
        body,
        notes,
    };
    validate_task(&task).map_err(|e| perr(file, e.to_string()))?;
    Ok(task)
}

/// `after` is everything following the closing `---\n`.
fn split_body_notes(after: &str, file: &str) -> Result<(String, Vec<Note>)> {
    let mut body_lines: Vec<&str> = Vec::new();
    let mut lines = after.lines();
    let mut notes = Vec::new();
    let mut in_notes = false;
    while let Some(line) = lines.next() {
        if line == NOTES_DELIMITER {
            if in_notes { return Err(perr(file, "second ## Notes heading")); }
            in_notes = true;
            continue;
        }
        if !in_notes { body_lines.push(line); continue; }
        if line.trim().is_empty() { continue; }
        notes.push(parse_note_line(line).ok_or_else(|| perr(file, format!("malformed note line {line:?}")))?);
    }
    let body = body_lines.join("\n").trim().to_string();
    Ok((body, notes))
}

fn parse_note_line(line: &str) -> Option<Note> {
    let rest = line.strip_prefix("- ")?;
    let (at, rest) = rest.split_once(" (")?;
    let (by, text) = rest.split_once("): ")?;
    crate::time::parse(at).ok()?;
    if by.is_empty() || text.is_empty() { return None; }
    Some(Note { at: at.into(), by: by.into(), text: text.into() })
}

pub fn validate_body(body: &str) -> Result<()> {
    if body.lines().any(|l| l == NOTES_DELIMITER) {
        return Err(Error::Validation(format!("body must not contain the reserved line {NOTES_DELIMITER:?}")));
    }
    Ok(())
}

pub fn validate_note_text(text: &str) -> Result<()> {
    if text.is_empty() { return Err(Error::Validation("note text must not be empty".into())); }
    if text.contains('\n') { return Err(Error::Validation("note text must be a single line".into())); }
    Ok(())
}

pub fn validate_task(t: &Task) -> Result<()> {
    if t.title.is_empty() || t.title.contains('\n') {
        return Err(Error::Validation("title must be a non-empty single line".into()));
    }
    if t.priority > 4 { return Err(Error::Validation("priority must be 0-4".into())); }
    if t.step.is_some() && t.plan.is_none() { return Err(Error::Validation("step requires plan".into())); }
    if let Some(s) = &t.spec && !s.starts_with("docs/specs/") {
        return Err(Error::Validation(format!("spec {s:?} must be under docs/specs/")));
    }
    if let Some(p) = &t.plan && !p.starts_with("docs/plans/") {
        return Err(Error::Validation(format!("plan {p:?} must be under docs/plans/")));
    }
    if t.depends.contains(&t.id) { return Err(Error::Validation("task cannot depend on itself".into())); }
    if let Some(o) = &t.owner && o.is_empty() { return Err(Error::Validation("owner must not be empty".into())); }
    validate_body(&t.body)?;
    for n in &t.notes { validate_note_text(&n.text)?; }
    Ok(())
}

pub fn serialize_task(t: &Task) -> String {
    let s = |v: &str| Value::Scalar(v.to_string());
    let mut pairs: Vec<(String, Value)> = vec![
        ("id".into(), s(&t.id.to_string())),
        ("title".into(), s(&t.title)),
        ("status".into(), s(t.status.as_str())),
        ("priority".into(), Value::Raw(t.priority.to_string())),
    ];
    if let Some(z) = t.size { pairs.push(("size".into(), s(z.as_str()))); }
    if let Some(o) = &t.owner { pairs.push(("owner".into(), s(o))); }
    pairs.push(("created".into(), s(&t.created)));
    pairs.push(("updated".into(), s(&t.updated)));
    pairs.push(("depends".into(), Value::List(t.depends.iter().map(|d| d.to_string()).collect())));
    pairs.push(("tags".into(), Value::List(t.tags.clone())));
    if let Some(v) = &t.spec { pairs.push(("spec".into(), s(v))); }
    if let Some(v) = &t.plan { pairs.push(("plan".into(), s(v))); }
    if let Some(v) = &t.step { pairs.push(("step".into(), s(v))); }

    let mut out = String::from("---\n");
    out.push_str(&frontmatter::serialize(&pairs));
    out.push_str("---\n");
    let body = t.body.trim_end();
    if !body.is_empty() {
        out.push('\n');
        out.push_str(body);
        out.push('\n');
    }
    if !t.notes.is_empty() {
        out.push('\n');
        out.push_str(NOTES_DELIMITER);
        out.push_str("\n\n");
        for n in &t.notes {
            out.push_str(&format!("- {} ({}): {}\n", n.at, n.by, n.text));
        }
    }
    out
}
```

```rust
use crate::error::{Error, Result};
use crate::format::{parse_task, serialize_task};
use crate::model::{Task, TaskId, is_valid_prefix};
use std::path::{Path, PathBuf};

pub const CONFIG_REL: &str = "tasks/.config.toml";

#[derive(Debug, Clone)]
pub struct Project {
    pub root: PathBuf,
    pub prefix: String,
}

#[derive(serde::Serialize, serde::Deserialize)]
struct Config { prefix: String }

impl Project {
    pub fn init(root: &Path, prefix: &str) -> Result<Project> {
        if !is_valid_prefix(prefix) {
            return Err(Error::Config(format!("prefix {prefix:?} must match [a-z][a-z0-9]{{1,7}}")));
        }
        let cfg = root.join(CONFIG_REL);
        if cfg.exists() { return Err(Error::Config(format!("{} already exists", cfg.display()))); }
        std::fs::create_dir_all(root.join("tasks"))?;
        std::fs::create_dir_all(root.join("docs/specs"))?;
        std::fs::create_dir_all(root.join("docs/plans"))?;
        let text = toml::to_string(&Config { prefix: prefix.into() }).expect("config serializes");
        std::fs::write(&cfg, text)?;
        Project::open(root)
    }

    pub fn open(root: &Path) -> Result<Project> {
        let root = root.canonicalize()?;
        let text = std::fs::read_to_string(root.join(CONFIG_REL))?;
        let cfg: Config = toml::from_str(&text).map_err(|e| Error::Config(format!("{CONFIG_REL}: {e}")))?;
        if !is_valid_prefix(&cfg.prefix) {
            return Err(Error::Config(format!("{CONFIG_REL}: bad prefix {:?}", cfg.prefix)));
        }
        Ok(Project { root, prefix: cfg.prefix })
    }

    pub fn locate(start: &Path) -> Result<Project> {
        let start = start.canonicalize()?;
        let mut dir: Option<&Path> = Some(&start);
        while let Some(d) = dir {
            if d.join(CONFIG_REL).is_file() { return Project::open(d); }
            dir = d.parent();
        }
        Err(Error::NoProject(start))
    }

    pub fn tasks_dir(&self) -> PathBuf { self.root.join("tasks") }

    pub fn task_path(&self, id: &TaskId) -> PathBuf { self.tasks_dir().join(format!("{id}.md")) }

    pub fn read_raw(&self, id: &TaskId) -> Result<String> {
        let path = self.task_path(id);
        if !path.is_file() { return Err(Error::TaskNotFound(id.to_string())); }
        Ok(std::fs::read_to_string(path)?)
    }

    pub fn read_task(&self, id: &TaskId) -> Result<Task> {
        let raw = self.read_raw(id)?;
        let task = parse_task(&raw, &format!("tasks/{id}.md"))?;
        if &task.id != id {
            return Err(Error::Parse { file: format!("tasks/{id}.md"), detail: format!("id field is {}", task.id) });
        }
        Ok(task)
    }

    fn task_files(&self) -> Result<Vec<(TaskId, PathBuf)>> {
        let mut out = Vec::new();
        for entry in std::fs::read_dir(self.tasks_dir())? {
            let path = entry?.path();
            let Some(name) = path.file_name().and_then(|n| n.to_str()) else { continue };
            let Some(stem) = name.strip_suffix(".md") else { continue };
            if stem.starts_with('.') { continue; }
            let id = TaskId::parse(stem).map_err(|_| Error::Parse {
                file: format!("tasks/{name}"), detail: "filename is not a valid task id".into(),
            })?;
            out.push((id, path));
        }
        out.sort();
        Ok(out)
    }

    pub fn scan(&self) -> Result<Vec<Task>> {
        self.task_files()?.into_iter().map(|(id, _)| self.read_task(&id)).collect()
    }

    /// Every readable task plus every error, for `check`. Files with an invalid
    /// id-shaped name are reported as errors too.
    pub fn scan_lenient(&self) -> (Vec<Task>, Vec<Error>) {
        let (mut tasks, mut errors) = (Vec::new(), Vec::new());
        let entries = match std::fs::read_dir(self.tasks_dir()) {
            Ok(e) => e,
            Err(e) => return (tasks, vec![e.into()]),
        };
        for entry in entries.flatten() {
            let path = entry.path();
            let Some(name) = path.file_name().and_then(|n| n.to_str()).map(str::to_string) else { continue };
            let Some(stem) = name.strip_suffix(".md") else { continue };
            if stem.starts_with('.') { continue; }
            match TaskId::parse(stem) {
                Err(_) => errors.push(Error::Parse { file: format!("tasks/{name}"), detail: "filename is not a valid task id".into() }),
                Ok(id) => match self.read_task(&id) {
                    Ok(t) => tasks.push(t),
                    Err(e) => errors.push(e),
                },
            }
        }
        tasks.sort_by(|a, b| a.id.cmp(&b.id));
        (tasks, errors)
    }

    pub fn write_task(&self, task: &Task) -> Result<()> {
        let tmp = self.tasks_dir().join(format!(".{}.tmp", task.id));
        std::fs::write(&tmp, serialize_task(task))?;
        std::fs::rename(&tmp, self.task_path(&task.id))?;
        Ok(())
    }

    pub fn new_id(&self) -> Result<TaskId> {
        for _ in 0..16 {
            let id = TaskId { prefix: self.prefix.clone(), hex: format!("{:06x}", fastrand::u32(..0x100_0000)) };
            if !self.task_path(&id).exists() { return Ok(id); }
        }
        Err(Error::Validation("could not allocate a free id after 16 attempts".into()))
    }
}
```

```rust
use crate::error::{Error, Result};
use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

#[derive(Debug, Default, serde::Serialize, serde::Deserialize)]
pub struct Registry {
    #[serde(default)]
    pub projects: BTreeMap<String, PathBuf>,
}

impl Registry {
    pub fn path() -> Result<PathBuf> {
        if let Some(x) = std::env::var_os("XDG_CONFIG_HOME") {
            return Ok(PathBuf::from(x).join("tasks/projects.toml"));
        }
        if let Some(h) = std::env::var_os("HOME") {
            return Ok(PathBuf::from(h).join(".config/tasks/projects.toml"));
        }
        Err(Error::Config("neither XDG_CONFIG_HOME nor HOME is set".into()))
    }

    pub fn load() -> Result<Registry> { Registry::load_from(&Registry::path()?) }

    pub fn load_from(path: &Path) -> Result<Registry> {
        if !path.exists() { return Ok(Registry::default()); }
        let text = std::fs::read_to_string(path)?;
        toml::from_str(&text).map_err(|e| Error::Config(format!("{}: {e}", path.display())))
    }

    pub fn save(&self) -> Result<()> { self.save_to(&Registry::path()?) }

    pub fn save_to(&self, path: &Path) -> Result<()> {
        if let Some(parent) = path.parent() { std::fs::create_dir_all(parent)?; }
        std::fs::write(path, toml::to_string(self).expect("registry serializes"))?;
        Ok(())
    }

    pub fn register(&mut self, prefix: &str, root: &Path) -> Result<()> {
```

```rust
    Init(InitOut),

pub fn render(out: &Output, format: Format) -> String {
    match format {
        Format::Json => serde_json::to_string(out).expect("output serializes"),
        Format::Pretty => pretty(out),
    }
}

    match out {
        Output::Init(o) => o.prefix.clone(),
    }
}

pub fn render_error(e: &Error) -> String {
    serde_json::json!({ "error": { "kind": e.kind(), "detail": e.to_string() } }).to_string()
}

/// stderr text for warnings in pretty mode.
pub fn pretty_warnings(warnings: &[String]) -> String {
```

```rust
use crate::output::{InitOut, Output};
use crate::registry::Registry;
use crate::repo::Project;

const SKILL_REL: &str = "skills/tasks/SKILL.md";

pub fn run(dir: Option<&Path>, prefix: Option<String>) -> Result<Output> {
    let root = match dir {
        Some(d) => d.to_path_buf(),
        None => std::env::current_dir()?,
    };
    let root = root.canonicalize()?;
    let prefix = match prefix {
        Some(p) => p,
        None => default_prefix(&root)?,
    };
    let mut registry = Registry::load()?;
    registry.register(&prefix, &root)?; // fails before touching the repo
    let project = Project::init(&root, &prefix)?;
    registry.save()?;
    let mut warnings = Vec::new();
    if !skill_installed(&project.root) {
        warnings.push("no tasks skill found at user or project level; install skills/tasks (see README)".into());
    }
    Ok(Output::Init(InitOut { prefix: project.prefix, root: project.root.display().to_string(), warnings }))
}

fn default_prefix(root: &Path) -> Result<String> {
    let name = root.file_name().and_then(|n| n.to_str())
        .ok_or_else(|| Error::Config("cannot derive a prefix from this directory; pass --prefix".into()))?;
    let p: String = name.chars().filter(|c| c.is_ascii_alphanumeric()).take(3).collect::<String>().to_lowercase();
    if !crate::model::is_valid_prefix(&p) {
        return Err(Error::Config(format!("derived prefix {p:?} is invalid; pass --prefix")));
    }
    Ok(p)
}

fn skill_installed(root: &Path) -> bool {
    let mut candidates: Vec<PathBuf> = vec![root.join(".claude").join(SKILL_REL)];
    if let Some(h) = std::env::var_os("HOME") {
        let h = PathBuf::from(h);
        candidates.push(h.join(".claude").join(SKILL_REL));
        candidates.push(h.join(".agents").join(SKILL_REL));
    }
    candidates.iter().any(|p| p.is_file())
}
```

```rust
use crate::error::{Error, Result};
use crate::model::{Task, TaskId};
use crate::registry::Registry;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DocKind { Spec, Plan }

impl DocKind {
    pub fn dir(self) -> &'static str {
        match self { DocKind::Spec => "docs/specs", DocKind::Plan => "docs/plans" }
    }
    pub fn name(self) -> &'static str {
        match self { DocKind::Spec => "spec", DocKind::Plan => "plan" }
    }
}

pub struct Resolver<'a> {
    pub project: &'a Project,
    pub registry: &'a Registry,
}

impl<'a> Resolver<'a> {
    pub fn new(project: &'a Project, registry: &'a Registry) -> Resolver<'a> {
        Resolver { project, registry }
    }

    /// `Ok(None)` when the id is unreachable (unregistered prefix, missing root, or
    /// missing file); `Err` when a file exists but cannot be parsed.
    pub fn resolve_task(&self, id: &TaskId) -> Result<Option<Task>> {
        let project;
        let p: &Project = if id.prefix == self.project.prefix {
            self.project
        } else {
            let Some(root) = self.registry.project_root(&id.prefix) else { return Ok(None) };
            if !root.join(crate::repo::CONFIG_REL).is_file() { return Ok(None); }
            project = Project::open(root)?;
            &project
        };
        match p.read_task(id) {
            Ok(t) => Ok(Some(t)),
            Err(Error::TaskNotFound(_)) => Ok(None),
            Err(e) => Err(e),
        }
    }

    pub fn resolve_doc(&self, kind: DocKind, name_or_path: &str) -> Result<String> {
        let dir = kind.dir();
        if name_or_path.contains('/') || name_or_path.ends_with(".md") {
            let rel = name_or_path.trim_start_matches("./");
            if !rel.starts_with(&format!("{dir}/")) {
                return Err(Error::Validation(format!("{} {rel:?} must be under {dir}/", kind.name())));
            }
            if !self.project.root.join(rel).is_file() {
                return Err(Error::DocNotFound(format!("{} {rel:?} does not exist", kind.name())));
            }
            return Ok(rel.to_string());
        }
        let mut matches: Vec<String> = Vec::new();
        let full = self.project.root.join(dir);
        if full.is_dir() {
            for entry in std::fs::read_dir(&full)? {
                let path = entry?.path();
                let Some(name) = path.file_name().and_then(|n| n.to_str()) else { continue };
                if name.ends_with(".md") && name.contains(name_or_path) {
                    matches.push(format!("{dir}/{name}"));
                }
            }
        }
        matches.sort();
        match matches.len() {
            0 => Err(Error::DocNotFound(format!("no {} matching {name_or_path:?} under {dir}/", kind.name()))),
            1 => Ok(matches.remove(0)),
            _ => Err(Error::Ambiguous(format!("{name_or_path:?} matches several {}s: {}", kind.name(), matches.join(", ")))),
        }
    }

    pub fn step_exists(&self, plan_rel: &str, step: &str) -> Result<bool> {
        let text = std::fs::read_to_string(self.project.root.join(plan_rel))
            .map_err(|_| Error::DocNotFound(format!("plan {plan_rel:?} does not exist")))?;
        Ok(text.lines().any(|l| heading_text(l) == Some(step)))
    }

    pub fn abs(&self, rel: &str) -> String {
        Path::new(&self.project.root).join(rel).display().to_string()
    }
}

/// `### Task 1: x` -> `Some("Task 1: x")`; non-headings -> None.
pub fn heading_text(line: &str) -> Option<&str> {
    let trimmed = line.trim_start_matches('#');
    if trimmed.len() == line.len() { return None; }
    trimmed.strip_prefix(' ').map(str::trim_end)
}
```

```rust
use super::Ctx;
use crate::error::Result;
use crate::model::{Size, Status, Task, TaskId};
use crate::output::{Counts, ListOut, Output, PrimeOut, TaskSummary};
use crate::query::{is_ready, sort_list, sort_ready};
use crate::repo::Project;
use crate::resolve::Resolver;

pub fn list(mut ctx: Ctx, statuses: Vec<String>, tags: Vec<String>, owner: Option<String>, all_projects: bool) -> Result<Output> {
    let statuses = statuses.iter().map(|s| Status::parse(s)).collect::<Result<Vec<_>>>()?;
    let mut tasks = ctx.project.scan()?;
    if all_projects {
        for (prefix, root) in &ctx.registry.projects {
            if *prefix == ctx.project.prefix { continue; }
            match Project::open(root) {
                Ok(p) => tasks.extend(p.scan()?),
                Err(e) => ctx.warnings.push(format!("project {prefix} at {}: {e}", root.display())),
            }
        }
    }
    tasks.retain(|t| {
        let status_ok = if statuses.is_empty() { t.status.is_open() } else { statuses.contains(&t.status) };
        let tags_ok = tags.iter().all(|g| t.tags.contains(g));
        let owner_ok = owner.as_ref().is_none_or(|o| t.owner.as_ref() == Some(o));
        status_ok && tags_ok && owner_ok
    });
    sort_list(&mut tasks);
    Ok(Output::List(ListOut { tasks: tasks.iter().map(TaskSummary::from).collect(), warnings: ctx.warnings }))
}

/// Ready tasks in ready order; pushes a warning per unreachable dependency.
pub fn ready_tasks(ctx: &mut Ctx, all: &[Task]) -> Result<Vec<Task>> {
    let r = Resolver::new(&ctx.project, &ctx.registry);
    let mut warnings = Vec::new();
    let lookup = |id: &TaskId| -> Option<bool> {
        if let Some(local) = all.iter().find(|t| &t.id == id) { return Some(!local.status.is_open()); }
        match r.resolve_task(id) {
            Ok(Some(t)) => Some(!t.status.is_open()),
            Ok(None) => None,
            Err(_) => None,
        }
    };
    let mut out: Vec<Task> = Vec::new();
    for t in all {
        if t.status != Status::Todo { continue; }
        for d in &t.depends {
            if lookup(d).is_none() { warnings.push(format!("{}: dependency {d} is unreachable", t.id)); }
        }
        if is_ready(t, &lookup) { out.push(t.clone()); }
    }
    sort_ready(&mut out);
    ctx.warnings.extend(warnings);
    Ok(out)
}

pub fn ready(mut ctx: Ctx, size: Option<String>, limit: Option<usize>) -> Result<Output> {
    let size = size.map(|s| Size::parse(&s)).transpose()?;
    let all = ctx.project.scan()?;
    let mut tasks = ready_tasks(&mut ctx, &all)?;
    if let Some(z) = size { tasks.retain(|t| t.size == Some(z)); }
    if let Some(n) = limit { tasks.truncate(n); }
    Ok(Output::List(ListOut { tasks: tasks.iter().map(TaskSummary::from).collect(), warnings: ctx.warnings }))
}

pub fn prime(mut ctx: Ctx) -> Result<Output> {
    let all = ctx.project.scan()?;
    let mut counts = Counts::default();
    for t in &all {
        match t.status {
            Status::Idea => counts.idea += 1, Status::Todo => counts.todo += 1,
            Status::Doing => counts.doing += 1, Status::Blocked => counts.blocked += 1,
            Status::Done => counts.done += 1, Status::Dropped => counts.dropped += 1,
        }
    }
    let ready = ready_tasks(&mut ctx, &all)?;
    let mut doing: Vec<Task> = all.iter().filter(|t| t.status == Status::Doing).cloned().collect();
    sort_list(&mut doing);
    Ok(Output::Prime(PrimeOut {
        prefix: ctx.project.prefix.clone(),
        counts,
        ready: ready.iter().map(TaskSummary::from).collect(),
        doing: doing.iter().map(TaskSummary::from).collect(),
        warnings: ctx.warnings,
    }))
}
```

```rust
/// Ids of dependencies that are open or unreachable.
pub fn open_deps(ctx: &Ctx, task: &Task) -> Result<Vec<String>> {
    let r = Resolver::new(&ctx.project, &ctx.registry);
    let mut open = Vec::new();
    for d in &task.depends {
        match r.resolve_task(d)? {
            Some(t) if !t.status.is_open() => {}
            _ => open.push(d.to_string()),
        }
    }
    Ok(open)
}

pub fn transition(ctx: &Ctx, task: &mut Task, to: Status, force: bool) -> Result<()> {
    if !Status::can_transition(task.status, to) {
        return Err(Error::InvalidTransition(task.status.as_str().into(), to.as_str().into()));
    }
    if to == Status::Done && task.status != Status::Done && !force {
        let open = open_deps(ctx, task)?;
        if !open.is_empty() {
            return Err(Error::OpenDependencies(task.id.to_string(), open.join(", ")));
        }
    }
    task.status = to;
    Ok(())
}
```

```rust
use crate::error::{Error, Result};
use std::collections::HashSet;

/// Depth-first search for a cycle reachable from `start`. `edges` yields a node's
/// dependencies, or `Ok(None)` when the node is unreachable (which is an error here:
/// a cycle cannot be ruled out). Edge direction: task -> its dependency.
pub fn find_cycle(
    start: &TaskId,
    edges: &dyn Fn(&TaskId) -> Result<Option<Vec<TaskId>>>,
) -> Result<Option<Vec<TaskId>>> {
    let mut done: HashSet<TaskId> = HashSet::new();
    let mut path: Vec<TaskId> = Vec::new();
    fn visit(
        node: &TaskId, edges: &dyn Fn(&TaskId) -> Result<Option<Vec<TaskId>>>,
        path: &mut Vec<TaskId>, done: &mut HashSet<TaskId>,
    ) -> Result<Option<Vec<TaskId>>> {
        if let Some(pos) = path.iter().position(|p| p == node) {
            let mut cycle = path[pos..].to_vec();
            cycle.push(node.clone());
            return Ok(Some(cycle));
        }
        if done.contains(node) { return Ok(None); }
        let deps = edges(node)?.ok_or_else(|| Error::UnresolvableId(node.to_string()))?;
        path.push(node.clone());
        for d in &deps {
            if let Some(c) = visit(d, edges, path, done)? { return Ok(Some(c)); }
        }
        path.pop();
        done.insert(node.clone());
        Ok(None)
    }
    visit(start, edges, &mut path, &mut done)
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum GraphFormat { Mermaid, Dot }

impl GraphFormat {
    pub fn parse(s: &str) -> Result<GraphFormat> {
        match s {
            "mermaid" => Ok(GraphFormat::Mermaid),
            "dot" => Ok(GraphFormat::Dot),
            other => Err(Error::Validation(format!("unknown graph format {other:?}; use mermaid or dot"))),
        }
    }
    pub fn as_str(self) -> &'static str { match self { GraphFormat::Mermaid => "mermaid", GraphFormat::Dot => "dot" } }
}

fn node_label(t: &Task) -> String {
    let size = t.size.map(|z| z.as_str()).unwrap_or("-");
    format!("{} P{} {} {}: {}", t.id, t.priority, size, t.status.as_str(), t.title.replace('"', "'"))
}

/// Edges point from dependency to dependent (the order work flows). Edges to tasks
/// not in `tasks` (e.g. closed ones when rendering open tasks only) are omitted.
pub fn render_graph(tasks: &[Task], format: GraphFormat) -> String {
    let shown: HashSet<&TaskId> = tasks.iter().map(|t| &t.id).collect();
    let mut s = String::new();
    match format {
        GraphFormat::Mermaid => {
            s.push_str("graph TD\n");
            for t in tasks {
                s.push_str(&format!("  {}[\"{}\"]\n", t.id.to_string().replace('-', "_"), node_label(t)));
            }
            for t in tasks {
                for d in t.depends.iter().filter(|d| shown.contains(d)) {
                    s.push_str(&format!("  {} --> {}\n", d.to_string().replace('-', "_"), t.id.to_string().replace('-', "_")));
                }
            }
        }
        GraphFormat::Dot => {
            s.push_str("digraph tasks {\n  rankdir=TB;\n");
            for t in tasks {
                s.push_str(&format!("  \"{}\" [label=\"{}\"];\n", t.id, node_label(t)));
            }
            for t in tasks {
                for d in t.depends.iter().filter(|d| shown.contains(d)) {
                    s.push_str(&format!("  \"{}\" -> \"{}\";\n", d, t.id));
                }
            }
            s.push_str("}\n");
        }
    }
    s
}
```

```rust
use crate::error::{Error, Result};

/// Fails if adding `candidate`'s current `depends` would create a cycle or pass through an unreachable id.
pub fn ensure_acyclic(ctx: &Ctx, candidate: &Task) -> Result<()> {
    let r = Resolver::new(&ctx.project, &ctx.registry);
    let edges = |id: &TaskId| -> Result<Option<Vec<TaskId>>> {
        if *id == candidate.id { return Ok(Some(candidate.depends.clone())); }
        Ok(r.resolve_task(id)?.map(|t| t.depends))
    };
    if let Some(cycle) = find_cycle(&candidate.id, &edges)? {
        let path: Vec<String> = cycle.iter().map(|c| c.to_string()).collect();
        return Err(Error::Cycle(path.join(" -> ")));
    }
    Ok(())
}

pub fn run(ctx: Ctx, id: String, on: Vec<String>, rm: Vec<String>) -> Result<Output> {
    let mut task = load(&ctx, &id)?;
    if !on.is_empty() {
        let r = Resolver::new(&ctx.project, &ctx.registry);
        for d in &on {
            let dep = TaskId::parse(d)?;
            if dep == task.id { return Err(Error::Cycle(format!("{dep} -> {dep}"))); }
            if r.resolve_task(&dep)?.is_none() { return Err(Error::UnresolvableId(dep.to_string())); }
            if !task.depends.contains(&dep) { task.depends.push(dep); }
        }
        ensure_acyclic(&ctx, &task)?;
    } else {
        for d in &rm {
            let dep = TaskId::parse(d)?;
            let before = task.depends.len();
            task.depends.retain(|x| x != &dep);
            if task.depends.len() == before {
                return Err(Error::Validation(format!("{} does not depend on {dep}", task.id)));
            }
        }
    }
    save(&ctx, &mut task)?;
    Ok(id_out(ctx, &task))
}
```

```rust
use super::{Ctx, apply_fields, id_out, load, save, transition};
use crate::cli::FieldArgs;
use crate::error::{Error, Result};

use crate::model::{Status, Task};

use std::io::Read;

pub fn check_invariants(original: &Task, edited: &Task) -> Result<()> {
    if edited.id != original.id { return Err(Error::Validation("id is immutable".into())); }
    if edited.created != original.created { return Err(Error::Validation("created is immutable".into())); }
    if edited.notes != original.notes { return Err(Error::Validation("notes are append-only; use `tasks note`".into())); }
    Ok(())
}

pub fn run(ctx: Ctx, id: String, title: Option<String>, status: Option<String>, force: bool, mut fields: FieldArgs) -> Result<Output> {
    let has_flags = title.is_some() || status.is_some() || fields.body.is_some() || fields.priority.is_some()
        || fields.size.is_some() || !fields.tags.is_empty() || !fields.depends.is_empty()
        || fields.spec.is_some() || fields.plan.is_some() || fields.step.is_some();
    if !has_flags { return editor(ctx, id); }

    let mut task = load(&ctx, &id)?;
    if fields.body.as_deref() == Some("-") {
        let mut s = String::new();
        std::io::stdin().read_to_string(&mut s)?;
        fields.body = Some(s);
    }
    if let Some(t) = title { task.title = t; }
    if let Some(s) = status { transition(&ctx, &mut task, Status::parse(&s)?, force)?; }
    apply_fields(&ctx, &mut task, &fields)?;
    save(&ctx, &mut task)?;
    Ok(id_out(ctx, &task))
}

fn editor(ctx: Ctx, id: String) -> Result<Output> {
    let original = load(&ctx, &id)?;
    let original_raw = ctx.project.read_raw(&original.id)?;
    let editor = std::env::var("EDITOR").ok().filter(|e| !e.is_empty())
        .ok_or_else(|| Error::Editor("EDITOR is not set".into()))?;
    let tmp = ctx.project.tasks_dir().join(format!(".{}.{:06x}.edit.md", original.id, fastrand::u32(..0x100_0000)));
    std::fs::write(&tmp, &original_raw)?;
    let tmp_display = tmp.display().to_string();
    let suffix = format!(" (edit kept at {tmp_display})");
    let keep = |e: Error| -> Error { e.with_suffix(&suffix) };

    let status = std::process::Command::new("sh").arg("-c").arg(format!("{editor} \"$1\"")).arg("tasks-edit").arg(&tmp).status()
        .map_err(|e| Error::Editor(format!("failed to run {editor}: {e}")))?;
    if !status.success() {
        return Err(Error::Editor(format!("{editor} exited with {status}; edit kept at {tmp_display}")));
    }

    let edited_raw = std::fs::read_to_string(&tmp)?;
    let mut edited = parse_task(&edited_raw, &tmp_display).map_err(keep)?;
    check_invariants(&original, &edited).map_err(keep)?;

    // Re-validate everything that depends on the repo, exactly as add/edit flags would.
    let r = Resolver::new(&ctx.project, &ctx.registry);
    if let Some(s) = &edited.spec { r.resolve_doc(DocKind::Spec, s).map_err(keep)?; }
    if let Some(p) = &edited.plan { r.resolve_doc(DocKind::Plan, p).map_err(keep)?; }
    if let (Some(p), Some(step)) = (&edited.plan, &edited.step) && !r.step_exists(p, step).map_err(keep)? {
        return Err(keep(Error::Validation(format!("heading {step:?} not found in {p}"))));
    }
    for d in &edited.depends {
        if r.resolve_task(d)?.is_none() { return Err(keep(Error::Validation(format!("dependency {d} is unreachable")))); }
    }
    super::dep::ensure_acyclic(&ctx, &edited).map_err(keep)?;
    let to = edited.status;
    edited.status = original.status;
    transition(&ctx, &mut edited, to, false).map_err(keep)?;

    if ctx.project.read_raw(&original.id)? != original_raw {
        return Err(Error::ConcurrentModification(original.id.to_string(), tmp_display));
    }
    save(&ctx, &mut edited)?;
    std::fs::remove_file(&tmp)?;
    Ok(id_out(ctx, &edited))
}
```

```rust
use super::Ctx;
use crate::error::{Error, Result};
use crate::model::{Task, TaskId};
use crate::output::{CheckOut, Finding, Output};
use crate::query::find_cycle;
use crate::resolve::{DocKind, Resolver};
use std::collections::BTreeSet;

fn finding(task: Option<&Task>, file: String, kind: &str, detail: String) -> Finding {
    Finding { id: task.map(|t| t.id.to_string()), file, kind: kind.into(), detail }
}

pub fn run(ctx: Ctx) -> Result<Output> {
    let (tasks, parse_errors) = ctx.project.scan_lenient();
    let mut errors: Vec<Finding> = Vec::new();
    let mut warnings: Vec<Finding> = Vec::new();

    for e in parse_errors {
        let file = match &e { Error::Parse { file, .. } => file.clone(), _ => "tasks/".into() };
        errors.push(finding(None, file, "parse", e.to_string()));
    }

    let r = Resolver::new(&ctx.project, &ctx.registry);
    let local: BTreeSet<&TaskId> = tasks.iter().map(|t| &t.id).collect();
    for t in &tasks {
        let file = format!("tasks/{}.md", t.id);
        for d in &t.depends {
            if d.prefix == ctx.project.prefix {
                if !local.contains(d) { errors.push(finding(Some(t), file.clone(), "dangling_dep", format!("depends on missing {d}"))); }
            } else if r.resolve_task(d)?.is_none() {
                warnings.push(finding(Some(t), file.clone(), "unreachable_dep", format!("depends on unreachable {d}")));
            }
        }
        for (kind, path) in [(DocKind::Spec, &t.spec), (DocKind::Plan, &t.plan)] {
            let Some(p) = path else { continue };
            if !p.starts_with(&format!("{}/", kind.dir())) {
                errors.push(finding(Some(t), file.clone(), "doc_outside_convention", format!("{} {p} is not under {}/", kind.name(), kind.dir())));
            } else if !ctx.project.root.join(p).is_file() {
                errors.push(finding(Some(t), file.clone(), "doc_missing", format!("{} {p} does not exist", kind.name())));
            }
        }
        if let (Some(p), Some(step)) = (&t.plan, &t.step) && ctx.project.root.join(p).is_file() && !r.step_exists(p, step)? {
            errors.push(finding(Some(t), file.clone(), "step_missing", format!("heading {step:?} not found in {p}")));
        }
    }

    // Cycles: one finding per distinct cycle (keyed by its sorted member set).
    let mut seen: BTreeSet<Vec<String>> = BTreeSet::new();
    let edges = |id: &TaskId| -> Result<Option<Vec<TaskId>>> {
        if let Some(t) = tasks.iter().find(|t| &t.id == id) { return Ok(Some(t.depends.clone())); }
        Ok(r.resolve_task(id)?.map(|t| t.depends))
    };
    for t in &tasks {
        let file = format!("tasks/{}.md", t.id);
        match find_cycle(&t.id, &edges) {
            Ok(None) => {}
            Ok(Some(cycle)) => {
                let mut key: Vec<String> = cycle[..cycle.len() - 1].iter().map(|c| c.to_string()).collect();
                key.sort();
                if seen.insert(key) {
                    let path: Vec<String> = cycle.iter().map(|c| c.to_string()).collect();
                    errors.push(finding(Some(t), file, "cycle", path.join(" -> ")));
                }
            }
            Err(Error::UnresolvableId(id)) => warnings.push(finding(Some(t), file, "cycle_unverifiable", format!("cannot verify acyclicity through unreachable {id}"))),
            Err(e) => return Err(e),
        }
    }

    Ok(Output::Check(CheckOut { errors, warnings }))
}
```

```markdown
name: tasks
description: Use when working in a repository that has a tasks/ directory (tasks/.config.toml) — start every session with `tasks prime`, pick work with `tasks ready`, and record progress with start/note/done instead of editing tasks/*.md by hand.

# tasks

`tasks` is the repository's task tracker: one markdown file per task under `tasks/`,
managed only through the CLI. Output is JSON unless `--pretty` is given.

## Session protocol

1. `tasks prime` — counts, the ready list, and who is working on what.
2. Pick from `tasks ready` (sorted by priority, then size). Never pick an `idea`; scope it first.
3. `tasks start <id>` before changing code. It records you as owner.
4. `tasks note <id> "<one line>"` whenever scope or understanding changes.
5. `tasks done <id> "<what landed>"` in the same commit as the code. If dependencies are
   still open, do not `--force` unless the dependency is genuinely irrelevant; say why in the message.
6. `tasks check` before committing. A failing check means a task and its plan/spec drifted apart; fix both.

Never edit `tasks/*.md` directly. `tasks edit <id> --title/--body/-p/--size/--tag/--depends/--spec/--plan/--step`
updates fields; `tasks edit <id>` with no flags opens `$EDITOR` and validates the result.

## Recording work

- An unscoped thought: `tasks add "<title>" --status idea -b "<why>"`. Ideas never appear in `ready`.
- A scoped task: `tasks add "<title>" -p <0-4> --size <xs|s|m|l|xl> --tag <group> [--spec <name>] [--plan <name> --step "<heading>"]`.
- Splitting: `tasks add` each piece, then `tasks dep <original> --on <piece>...` (or `tasks drop <original> "split into …"`), and `tasks note <original> "split into <ids>"`.
- Blocking on another project: `tasks dep <id> --on <prefix>-<hex>`; the other project must be registered (`tasks init` there).
- Id collision after a merge (git add/add conflict on the same `tasks/<id>.md`): keep one file, rename the other to a fresh id, fix its `id` field, then run `tasks check` and repair any `depends` it reports.

## With superpowers

- **brainstorming** writes the spec to `docs/specs/YYYY-MM-DD-<topic>-design.md`. After approval: one task per deliverable, `--spec <topic>`.
- **writing-plans** writes the plan to `docs/plans/YYYY-MM-DD-<topic>.md`. One task per `### Task N:` heading:
  `tasks add "<heading>" --plan <topic> --step "Task N: <title>" --depends <previous-task-id>`.
- **executing-plans / subagent-driven-development**: `tasks start` a step before implementing, `tasks done` when its commit lands.
- Plan headings are the drift contract: renaming or removing a heading under an open task fails `tasks check`. Update the task in the same change.
```

```markdown
# tasks

A fast, file-based task tracker for software projects, built for coding agents and the
humans supervising them. One markdown file per task, checked into the project; a single
Rust binary as the only writer. JSON output by default.

Design: [`docs/specs/2026-08-29-tasks-design.md`](docs/specs/2026-08-29-tasks-design.md).
Implementation plan: [`docs/plans/2026-08-29-tasks.md`](docs/plans/2026-08-29-tasks.md).

## Install

    cargo install --path .

## Use

    cd <repo>
    tasks init --prefix sci          # creates tasks/, docs/specs/, docs/plans/; registers the project
    tasks add "Bank the ledger" -p 1 --size m --tag ledger
    tasks ready                      # what can be worked on now (JSON)
    tasks --pretty ready             # same, as a table (or export TASKS_FORMAT=pretty)
    tasks start sci-4f2a9c
    tasks note sci-4f2a9c "spec §4 no longer holds"
    tasks done sci-4f2a9c "landed in 1a2b3c"
    tasks check                      # validate files, links, plan steps, dependencies

Run `tasks --help` for the full command list.

## Agent skill

`skills/tasks/SKILL.md` teaches agents the session protocol. Install it once at user level
so it applies to every project:

    mkdir -p ~/.claude/skills && ln -s "$PWD/skills/tasks" ~/.claude/skills/tasks
    mkdir -p ~/.agents/skills && ln -s "$PWD/skills/tasks" ~/.agents/skills/tasks   # other harnesses

or per project, when a project needs to pin its own copy:

    mkdir -p <repo>/.claude/skills && cp -r skills/tasks <repo>/.claude/skills/tasks

`tasks init` warns when neither location has the skill.

## Adopting in an existing project

1. Move design specs to `docs/specs/` and plans to `docs/plans/` (`git mv`), fixing links.
2. `tasks init --prefix <p>`.
3. Install the skill and mention it in the project's CLAUDE.md / AGENTS.md.
4. Add `tasks check` to the test script or pre-commit hook.
```
