# Task move implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `tasks move <id> --to <prefix>` moves one task to another registered project under
a new id. It carries the task's history verbatim and leaves a read-only `moved` tombstone
that points to the new id.

**Architecture:** The record gains a `moved` status and two pointer fields. One small
module, `src/tombstone.rs`, owns the pointer rules: write refusals, dependency
evaluation, and cycle edges. Every existing reader calls it instead of interpreting
`moved` itself. The move itself lives in `src/moving/`, modeled on `src/rename/`:
- a host-local journal records the exact bytes to write;
- a pure `classify` decides fresh, resume, complete, or refuse;
- idempotent phases M2–M8 run under both prefix locks and the registry lock.

**Tech Stack:** Rust 2024, clap, serde/toml, sha2 (already a dependency).

**Spec:** `docs/specs/2026-10-08-task-move-design.md` (approved after review round 3).
Section numbers below (§3.4, §4.3, …) are the spec's.

## Global Constraints

- **JSON output is the contract.** This plan makes only the changes the spec approves:
  - the task object gains optional `moved_to` and `moved_from`;
  - `status` gains `moved`;
  - the new `move` output object;
  - the new check kinds `moved_dep`, `move_incomplete`, `move_counterpart_unreachable`
    and `move_pending`;
  - the new error kinds `moved` and `move_pending`;
  - `Counts` gains `moved` (a consequence of the new status: `total` must still count
    every record).
- **Fail early with a typed error; no silent fallbacks.** Every refusal is an `Error`
  variant from `src/error.rs`.
- **No routing of writes through a tombstone.** Reads may follow `moved_to`; writes refuse.
- **Recovery covers process death, not power loss.** No `fsync` is added (spec §4.4).
- **Tests run through the front door.**
  - Focused runs: `just test-one <filter>` (unit) or `just test-one --test move <name>`
    (integration).
  - `just test-fast` before every commit.
  - Never call `cargo test` directly.
- **There is no library target.** Unit tests in `src/` run under the binary; the
  `test-one` filter reaches them.
- **`just check` before every commit** (fmt, clippy `-D warnings`, `tasks check`).
- **Conventional commits, no AI-attribution trailers.**
- **Every task ends by reinstalling and closing its own step task, in the same commit as
  the code** (AGENTS.md):
  1. `cargo install --path .`
  2. `tasks done <step id> "<what landed>"`

  The step ids are the children filed for this plan's `### Task N:` headings; find
  yours with `tasks list --plan task-move`.
- **`tasks check` must stay clean.** Each `### Task N:` heading is linked to a child
  task; renaming a heading without updating that task fails the gate.
- **Integration tests live in a new `tests/move.rs`** using `tests/common::TestEnv`.
  `TestEnv` scrubs `XDG_*`, so state lands under `env.home/.local/state/tasks/`. Every
  test therefore has scratch config and state, as the spec's §6 requires.

## Review Focus

These are inputs and conditions the spec implies but no acceptance case names. Each
line names the test that pins it.

1. **An id spelled through a retired prefix alias or as a bare suffix.** `move` and the
   tombstone refusal must treat it as the canonical id: the refusal names the new id,
   and the journal is keyed by the canonical source. Test:
   `move_accepts_alias_and_suffix_spellings` (Task 6).
2. **A dependent in the same project as the source.** `dots-b` depends on `dots-a`, which
   moves. `dots-b` must stay blocked, and `check` in `dots` must warn `moved_dep`. Local
   dependencies are read from the scan, not the resolver, so this path is separate.
   Test: `local_dependent_follows_the_pointer` (Task 3).
3. **Moving the same task twice** (`dots-a` → `wali-n` → `ops-m`). Evaluation follows
   the chain, and `check` reports no `move_incomplete` for the middle record. That
   record is both a tombstone and a `moved_from` destination. Test:
   `chained_moves_follow_to_the_end` (Task 4).
4. **A move back to the source project** (`wali-n --to dots`). It mints a fresh `dots`
   id, never reuses `dots-a`. Test: `moving_back_mints_a_fresh_id` (Task 6).
5. **`move` run from a worktree of the source project.** The tombstone is written in the
   checkout `load` would write, the destination at its registered root, and the carried
   park names the destination's `resume_root`. Test:
   `move_from_a_source_worktree_writes_the_local_record` (Task 6).

```rust
//! The `moved` tombstone and the pointer between a moved task's two records. See
//! docs/specs/2026-10-08-task-move-design.md §3.

use crate::error::{Error, Result};
use crate::model::{Status, Task};

/// A tombstone carries exactly one pointer, to another project; a destination names
/// another project as its source. Anything else is a hand edit outside `tasks move`.
pub fn validate(task: &Task) -> Result<()> {
    match (task.status, &task.moved_to) {
        (Status::Moved, None) => {
            return Err(Error::Validation(format!("{} is moved but has no moved_to", task.id)));
        }
        (Status::Moved, Some(to)) if to.prefix == task.id.prefix => {
            return Err(Error::Validation(format!(
                "{} moved_to {to} is in the same project", task.id
            )));
        }
        (status, Some(_)) if status != Status::Moved => {
            return Err(Error::Validation(format!(
                "{} has moved_to but status {}", task.id, status.as_str()
            )));
        }
        _ => {}
    }
    if let Some(from) = &task.moved_from
        && from.prefix == task.id.prefix
    {
        return Err(Error::Validation(format!(
            "{} moved_from {from} is in the same project", task.id
        )));
    }
    Ok(())
}
```

```rust
use crate::model::TaskId;

/// Every write command loads through `commands::load`; this is its tombstone guard.
pub fn refuse_write(task: &Task, spells: impl Fn(&str) -> bool) -> Result<()> {
    let (Status::Moved, Some(to)) = (task.status, &task.moved_to) else {
        return Ok(());
    };
    let args: Vec<String> = std::env::args()
        .skip(1)
        .map(|arg| if spells(&arg) { to.to_string() } else { arg })
        .collect();
    Err(Error::Moved(format!(
        "{} moved to {to}; run `tasks {}` instead",
        task.id,
        args.join(" ")
    )))
}

/// A new dependency or parent must name the live record, never a tombstone.
pub fn refuse_reference(task: &Task, role: &str) -> Result<()> {
    match (task.status, &task.moved_to) {
        (Status::Moved, Some(to)) => Err(Error::Moved(format!(
            "{role} {} moved to {to}; name {to} instead",
            task.id
        ))),
        _ => Ok(()),
    }
}
```

```rust
use std::collections::BTreeSet;

/// The record a dependency on `first` means: itself when live, else the end of its
/// `moved_to` chain (spec §3.4). `None` when a hop is unreachable or the chain revisits an
/// id; callers already treat `None` as an open, unreachable dependency.
pub fn follow(
    first: Option<Task>,
    mut resolve: impl FnMut(&TaskId) -> Result<Option<Task>>,
) -> Result<Option<Task>> {
    let mut seen = BTreeSet::new();
    let mut current = first;
    while let Some(task) = current {
        let (Status::Moved, Some(to)) = (task.status, task.moved_to.clone()) else {
            return Ok(Some(task));
        };
        if !seen.insert(task.id.clone()) {
            return Ok(None);
        }
        current = resolve(&to)?;
    }
    Ok(None)
}

/// The edges a record contributes to the dependency graph. A tombstone's retained
/// `depends` are history; its only edge is its pointer (spec §3.4).
pub fn edges(task: &Task) -> Vec<TaskId> {
    match (task.status, &task.moved_to) {
        (Status::Moved, Some(to)) => vec![to.clone()],
        _ => task.depends.clone(),
    }
}
```

```rust
pub fn classify(s: &Snapshot) -> Recovery {
    let j = &s.journal;
    let original = FileState::Digest(j.source_digest.clone());
    let tombstone = FileState::Digest(digest(j.tombstone_text.as_bytes()));
    let target = FileState::Digest(digest(j.target_text.as_bytes()));
    if s.source != original && s.source != tombstone {
        return Recovery::Refuse(format!(
            "{} no longer matches the journal or the tombstone it would write; it changed during the move",
            j.source
        ));
    }
    if s.target != FileState::Absent && s.target != target {
        return Recovery::Refuse(format!("{} exists with bytes the journal did not write", j.target));
    }
    if s.source == tombstone && s.target == FileState::Absent {
        return Recovery::Refuse(format!(
            "{} is already a tombstone but {} is missing", j.source, j.target
        ));
    }
    for attachment in &j.attachments {
        let want = FileState::Digest(attachment.sha256.clone());
        let here = s.source_files.get(&attachment.name) == Some(&want);
        let there = s.target_files.get(&attachment.name) == Some(&want);
        if !here && !there {
            return Recovery::Refuse(format!(
                "attachment {} has no copy with its journal digest in {} or {}; restore it from a \
                 verified backup, then rerun",
                attachment.name, j.source, j.target
            ));
        }
    }
    if s.target_park.is_some() && s.target_park != j.target_park {
        return Recovery::Refuse(format!("{}'s park differs from the one the journal carries", j.target));
    }
    if s.target_escalation.is_some() && s.target_escalation != j.target_escalation {
        return Recovery::Refuse(format!("{}'s escalation differs from the journal's", j.target));
    }
    Recovery::Resume
}
```

```rust
#[test]
fn undo_from_the_journal_restores_the_original_park() {
    // Spec §6 case 10: the §4.4 manual undo, performed by the test from the journal.
    let mut env = TestEnv::new();
    let dots = env.init("dots");
    let wali = env.init("wali");
    let a = id_of(env.json(&dots, &["add", "A", "-p", "2"]));
    env.json(&dots, &["park", &a, "pick up the parser"]);
    let code_worktree = dots.join(".worktrees/x").display().to_string();
    let store_path = env.claim_store("dots");
    let text = std::fs::read_to_string(&store_path).unwrap();
    let mut parks: toml::Value = toml::from_str(&text).unwrap();
    parks["parks"][a.as_str()]["worktree"] = toml::Value::String(code_worktree.clone());
    std::fs::write(&store_path, toml::to_string(&parks).unwrap()).unwrap();
    let original = parks["parks"][a.as_str()].clone();

    env.cmd(&dots).env("TASKS_MOVE_STOP_AFTER", "store")
        .args(["move", &a, "--to", "wali"]).assert().success();
    let journal: toml::Value =
        toml::from_str(&std::fs::read_to_string(journal_path(&env, &a)).unwrap()).unwrap();
    assert_eq!(journal["source_park"]["worktree"].as_str(), Some(code_worktree.as_str()));
    assert_eq!(journal["target_park"]["worktree"].as_str(), Some(wali.to_str().unwrap()));
    let n = journal["target"].as_str().unwrap().to_string();
    assert_eq!(store(&env, "wali")["parks"][n.as_str()], journal["target_park"]);

    // Undo, restore first and delete last.
    std::fs::write(dots.join(format!("tasks/{a}.md")), journal["source_text"].as_str().unwrap()).unwrap();
    let mut source_store = store(&env, "dots");
    source_store["parks"].as_table_mut().unwrap().insert(a.clone(), journal["source_park"].clone());
    std::fs::write(&store_path, toml::to_string(&source_store).unwrap()).unwrap();
    assert_eq!(store(&env, "dots")["parks"][a.as_str()], original);
    let mut target_store = store(&env, "wali");
    target_store["parks"].as_table_mut().unwrap().remove(&n);
    std::fs::write(env.claim_store("wali"), toml::to_string(&target_store).unwrap()).unwrap();
    std::fs::remove_file(wali.join(format!("tasks/{n}.md"))).unwrap();
    std::fs::remove_file(journal_path(&env, &a)).unwrap();

    assert_eq!(env.json(&dots, &["show", &a])["task"]["status"], "todo");
    assert!(env.check(&dots)["errors"].as_array().unwrap().is_empty());
    assert!(env.check(&wali)["errors"].as_array().unwrap().is_empty());
}
```
